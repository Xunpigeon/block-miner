## 1. 这是什么游戏

《方块矿工：深层开采》—— 方块沙盒 / 像素采矿小游戏，7 个矿区约 1 小时主线。
每局 15 秒：点方块挖矿 → 掉落入包 → 结算金币 → 回营地买天赋/强化 → 进更深的矿区。
每关解锁一把新工具（木镐→石镐→铁镐→钻石镐→激光→震荡器→深核钻机），每格矿是 6–14 层的堆叠。

## 2. 美术是怎么进游戏的（重要，先理解这条链）

```
art/_src/*.mjs      ← 现在所有图都是「代码画出来」的生成器（像素画在 canvas 上）
        ↓  node art/_src/gen.mjs
art/<分组>/*.png    ← 落盘的像素图（200 张 / 493KB）
art/manifest.json   ← 键名 → 图片路径的映射（131 个键）
        ↓  node build.mjs（把 manifest 里的图 base64 内联进单文件）
index.html          ← 最终产物，双击即玩，零外部请求
```

运行时由 `src/00-art.js` 暴露成 `BM.ART.one(key, index)`；**任何一张图缺失或没解码完，代码会自动回退到程序化绘制**，不会白屏。
所以你**可以分批交图**，先给方块、再给背景、再给 UI，随时都能玩。
