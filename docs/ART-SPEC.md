# 《方块矿工》美术资源规格书（交给绘画 Agent 用）

> 这份文档由代码现状反推而来：**游戏里没有任何图片文件**，全部是 Canvas 程序化生成 + CSS。
> 目标是把它们替换成一套像素 RPG 风格的手绘位图，风格要求：一眼能看出是方块矿洞世界（MC 同人感），但光影与背景要达到像素 RPG 的水准。

## 0. 一句话交接

做一套 32×32 的方块贴图 + 4 矿种掉落物 + 三层矿洞视差背景 + 一整套像素 UI 九宫格与图标，
全部 PNG、透明背景、无抗锯齿、无渐变、32 的整数倍对齐，按本文命名放进 art/ 目录。

## 2. 风格定义（给绘画 Agent 的硬约束）

- **像素格**：所有美术按 32×32 网格绘制（背景 256×256 平铺或 1170×2532 竖屏整图），像素边缘必须锐利，禁止抗锯齿、禁止羽化。
- **光照**：单一光源来自**屏幕上方偏左**，方块顶面稍亮、右下压暗；矿洞里有冷暖对比（岩壁冷蓝灰，矿脉/火光暖橙）。
- **配色**：见 §3 色板，不要自创高饱和粉紫，整体是「深色矿洞 + 暖色矿脉 + 冷蓝环境光」。
- **辨识度**：石头是灰色带斑驳颗粒；煤是灰底 + 大块黑团（占 25–35% 面积）；铁是灰底 + 米褐团块；晶石是深紫岩底 + 紫青菱形晶体。**不要**出现任何 Minecraft 原版贴图、图标或字体。
- **禁止**：文字、水印、签名、外发光模糊、塑料高光、3D 渲染感、渐变条带、超过 32 色/图。

## 5. 交付技术规范

1. 全部 PNG-24 带 alpha，不要 JPG，不要 WebP。
2. 32×32 的图必须**像素对齐**（内容压在 32 网格上），不要缩放模糊。
3. 同一组图**同一光照方向**（上偏左），同一组图**同样的对比度**，方便并排。
4. 九宫格图必须留 8px 边角不可拉伸，中间 8×8 可重复。
5. 背景必须**四边可无缝平铺**（左右上下都要接得上），给一张 512×512 的 2×2 预览图证明无缝。
6. 不要在任何图里写文字（标题图除外）。
7. 命名严格按 §4，全部小写、下划线、序号从 0 开始。
8. 交付时附一张 `art/contact-sheet.png` 拼版预览（所有图按目录排开，便于我一眼验收）。

## 6. 字体建议

UI 文字目前用系统字体。若要统一像素风，推荐挑一款**明确开源许可（OFL/MIT）的中文像素字体**（例如 Fusion Pixel / Zpix 一类），
由你确认许可后放进 `art/font/`，我在 style.css 里用 @font-face 内联（base64）。**不要**用任何游戏自带字体。

## 8. 我这边怎么接（你交图后我做的事，先告诉你以便对齐）

1. 图片放 `art/`（按 §4 命名）；`build.mjs` 会把被引用到的图 **base64 内联**进 index.html，保持单文件交付。
2. 蓝图里加一份 `art/manifest.json`：`{"tiles.ore.stone.normal":["art/tiles/ore_stone_normal_0.png",...]}`，我用它建贴图表。
3. 03-grid 优先用贴图表；缺图自动退回现有程序化贴图（所以可以分批交付，先给方块，再给 UI）。
4. 背景三层用 CSS 或 canvas 平铺 + 不同滚动速度；灰尘与光柱用透明层叠加。
