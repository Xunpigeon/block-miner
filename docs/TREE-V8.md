**关键理解（如与你的意图不符请指出）**：

1. 图上大量「同上」的圆圈 = **同一个节点的多级**，不是多个节点。我把它做成一个节点带 3–8 级，卡上显示 `Lv x/N`。
2. 工具（石镐/铁镐/钻石/激光/震荡/深核钻机）是**解锁型节点**，各占一个位置，串成一条链。
3. 中心是「开始挖矿」，效果 = 所有武器伤害 +1，第一局结束必买得起。

## 3. 价格（我定，随"深度"缩放）

- 节点深度 = 离中心的步数（1..7），价格倍率沿用 `zoneCoinTier` 同量级（1/6/30/150/750/3800/19000）。
- 多级价格 = 首级 × 1.9^(lv-1)。
- 首级价（第 1 层深度）：`atk` 300、`spd` 400、`settle` 250、`ore` 600、`chain` 500、`tntDrop` 800。
- 工具链：石镐 500 / 铁镐 2,600 / 钻石 12,000 / 激光 60,000 / 震荡 320,000 / 深核 1,800,000（深度缩放后）。

## 4. 操作方式统一（你要求）

- **取消"单点类"与"按住类"的区别**：所有工具都支持 `点按 = 攻击一次` 与 `按住 = 自动连发`。
- **点击落在攻击频率之外不算数**（不排队、不缓存），即回到"tap 也受 interval 约束"——上一轮加的 0.09 秒旁路取消。
