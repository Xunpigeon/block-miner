# v7：单一货币 · 放射状天赋树

> 用户决定：3 2 1 1 —— ① 天赋与强化合并成一个系统；② 保留 3 条枝的职责（采掘/矿脉/采集），强化作为可重复升级的节点并入；③ 每关 2 个机制型节点；④ 允许同枝跳级。
> 形态：**从一个中心节点向四周放射**。中心是第一颗节点「所有武器伤害 +1」，第一局结束一定买得起；之后向六个方向分叉，越往外越贵越强。

## 1. 结构（这是本轮唯一的视觉变化，内容不变）

```
                    采掘·连锁            采掘·威力
                        \                 /
                          \             /
   矿脉·富矿  ───────────  ● 中心  ───────────  采集·时间
                          /             \
                        /                 \
                    矿脉·层数            采集·触发
```

- **中心节点**：`所有武器伤害 +1`，价格 = 第 1 关首局的 60–80% 收入（打完一局必买得起）。
- **6 条放射车道**（lane）：采掘 ×2、矿脉 ×2、采集 ×2。每条 lane 是一条由内向外的链。
- **7 个环**（ring）：ring N 对应第 N 关的节点（价格随该关缩放），所以「越往外越贵越强」天然成立。
- 6 lane × 7 ring = 42 个天赋节点 + 中心 1 个 + **合并进来的 5 条强化**（作为 ring 1 上额外的可重复节点，`maxLevel 5–10`）。
- 同 lane 内允许**跳级**（Q4=1）：只要上一个已购，可以直接买更外圈的（前置只锁同 lane 的上一个）。

## 2. 五个「强化」怎么并入

| 原强化 | 新位置 | 级数 | 每级 |
|---|---|---:|---|
| 工具威力 | 采掘·威力 lane，ring 1 | 5 | +1 伤害 |
| 幸运齿轮 | 采集·触发 lane，ring 1 | 10 | 连锁概率 +2pp |
| 矿石精炼 | 矿脉·富矿 lane，ring 1 | 10 | 本局结算 ×1.035 |
| 作业时间 | 采集·时间 lane，ring 1 | 10 | +0.5 秒 |
| 富矿精炼 | 矿脉·层数 lane，ring 1 | 10 | 富矿掉落 +8% |

> 强化面板（`#bm-drawer-upgrades` 与营地「强化」按钮）本轮**删除**；所有花费都在天赋树里。

## 3. 节点视觉（解决「树大了看不清」）

- 节点是**圆形徽章**（直径 34–40px）：已购=实心橙、可买=橙色描边+呼吸、未解锁=灰、未到达（关未开）=更暗。
- 圆心显示 **1 个字符**（按 lane 取：力/连/富/层/时/触 之类），不放大段文字。
- **点击节点 → 底部弹出详情卡**：名称 / 效果一句话 / 价格 / 状态 / 购买按钮。详情卡是唯一显示长文本的地方，字号 ≥12px。
- 连线：SVG 细线，已购=亮橙、可买=虚线、未解锁=暗灰；lane 之间用颜色区分（6 色，低饱和）。
- 树可**拖动平移 + 双指/按钮缩放**；默认视图以中心为锚，显示到 ring 3，外圈可拖出去看。

## 4. 数据模型（01-config.js 提供，UI 只渲染）

```js
CONFIG.tree = {
  center: { id, name, desc, cost, effect },
  lanes: [ { id, name, angle }  // 6 条，角度决定放射方向
         ],
  nodes: [ { id, name, desc, lane, ring, cost, effect, requires:[id], maxLevel } ]
};
```

- `ring` = 1..7（对应关卡，决定价格倍率与解锁）；`lane` = 6 个方向之一。
- `requires` 只指向**同 lane 的上一个节点**（实现跳级：买更外圈只需同 lane 内环已购）。
- 中心节点 `requires: []`，第一局结束就能买。
- 价格：天赋节点 = tierBase[tier] × zoneCoinTier[ring]；强化节点 = baseCost × 1.8^level × upgradeZoneMult[ring]（沿用现有公式）。
